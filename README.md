# Shelper

Projeto para a nota M2 (Métodos Ágeis, UMC): um sistema para apoiar times ágeis, que automatiza os cálculos do Scrum e reduz o tempo gasto na análise da Sprint.

## O que é

O Shelper recebe um arquivo TSV ou CSV com as datas dos cartões do board (criação, início, revisão e conclusão) e mostra, num dashboard online, Lead Time, Cycle Time, Throughput, WIP, Velocity, Burndown, CFD e o gargalo do fluxo, comparados às metas do time.
